# Konya Korsan Taksi

Konya korsan taksi Türkiye'nin en geniş ilinde çalışır ve mesafeler buna göredir. Havalimanı merkez ilçelere yakındır: Selçuklu'dan 19, Meram'dan 20, Karatay'dan 21 kilometre. Otuz bir ilçenin en uzağı Çeltik'tir; 209 kilometre, 2 saat 49 dakika.

Mevlana Müzesi ve Alaaddin Tepesi çevresi yürünür, Sille için araç istenir. Aralık ayındaki Şeb-i Arus haftasında otel ile salon arası yoğunlaşır. Çumra'daki Çatalhöyük 65 kilometre, göl kıyısındaki Beyşehir 108 kilometredir.
